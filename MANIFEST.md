# Package manifest

This file describes the intended contents of the NATRIX reproducibility archive.
The authoritative, machine-readable list is `MANIFEST.csv`, and the per-file
hashes are in `SHA256SUMS.txt`; both are generated by
`submission/make_package.py` in the source workspace.

## Top-level layout

| Path | Kind | Description |
|---|---|---|
| `README.md` | documentation | Package overview, quick start, citation and licence status |
| `REPRODUCIBILITY.md` | documentation | Environment, data, protocol, commands, claim-to-artifact map, exclusions |
| `MANIFEST.md` | documentation | This file |
| `MANIFEST.csv` | metadata | Path, category, byte size and SHA-256 for every payload file |
| `SHA256SUMS.txt` | metadata | `sha256sum -c`-compatible checksums |
| `CITATION.cff` | metadata | Citation metadata with the public repository URL |
| `requirements.txt` | environment | Pinned Python dependencies |
| `LICENSE.md` | legal | Dual licence: MIT for code, CC BY 4.0 for documentation |
| `NATRIX_Q1_Manuscript/` | code and evidence | The evaluation workspace (see below) |
| `Ai-Agent/` | production code | Unmodified production modules imported by the evaluation |

## Inclusion rules

Included:

- All authored experiment, test, table, figure and manuscript-build code.
- The frozen protocol and deviation log.
- All JSON, CSV, JSONL, NPZ and log result files, except the excluded parquet
  caches and stray `nj*.npy` intermediates.
- All generated tables and figures.
- The TLA+ model, configurations, mutants, Python formal models and verification
  results, excluding TLC state dumps and trace files.
- The ONNX gate and threat-typing models and the parity report.
- The two unmodified production Python modules and the JavaScript extractor
  needed to run the evaluation and latency harness.
- Data provenance (`data/README.md`, `data/manifest.json`) without raw corpora.
- The compiled Elsevier and IEEE PDFs and their sources.

Excluded:

- Raw corpora and processed request caches.
- Parquet replay caches.
- Third-party binaries (Tectonic, JRE, `tla2tools.jar`).
- Editor/agent state, caches, backups and build intermediates.
- Earlier manuscript drafts superseded by the short and IEEE versions.
- The archive itself (`submission/dist/`).

## Checksums

`MANIFEST.csv` columns:

```text
path,category,bytes,sha256
```

`SHA256SUMS.txt` uses the standard format:

```text
<sha256>  <path>
```

To verify on Linux/macOS:

```bash
sha256sum -c SHA256SUMS.txt
```

On Windows PowerShell:

```powershell
Get-Content SHA256SUMS.txt | ForEach-Object {
  $hash, $path = $_ -split '  ', 2
  if ((Get-FileHash $path -Algorithm SHA256).Hash -ne $hash.ToUpper()) {
    Write-Error "checksum mismatch: $path"
  }
}
```
