# NATRIX reproducibility package

This package accompanies the manuscript:

> Ahire Nameet Sudam and D. D. Ambawade, "NATRIX: An Auditable
> Feature-Admission and Promotion Protocol for Inline HTTP Attack Detection,"
> manuscript under review, 2026.

It contains the code, frozen protocol, measured result files, generated tables
and figures, formal models, ONNX artifacts, and manuscript build pipeline used
for the offline-corpus evaluation.

**Repository status (2026-11-14).** Version 1.0.0 is published at
<https://github.com/NameetAhire/natrix-auditable>. No DOI is
minted. Cite the manuscript and the repository URL; the repository is the
authoritative artifact for the offline-corpus results.

## What is included

| Directory | Contents |
|---|---|

| `NATRIX_Q1_Manuscript/experiments/tests/` | Property-based and exhaustive tests for CPPP and trust decay |
| `NATRIX_Q1_Manuscript/experiments/run_all.ps1` | Main experiment queue (PowerShell) |
| `NATRIX_Q1_Manuscript/protocol/` | Frozen analysis plan, feature candidates, deviations D1--D14, review response |
| `NATRIX_Q1_Manuscript/experiments/results/` | Measured JSON, CSV, JSONL, NPZ and log outputs |
| `NATRIX_Q1_Manuscript/tables/` | Generated manuscript tables and supplementary tables |
| `NATRIX_Q1_Manuscript/figures/` | Generated manuscript figures (PDF and PNG) |
| `NATRIX_Q1_Manuscript/artifacts/formal/` | TLA+ model, configurations, mutants, Python CPPP/trust-decay models, verification logs |
| `NATRIX_Q1_Manuscript/artifacts/models/` | ONNX gate and threat-typing models, parity report |
| `NATRIX_Q1_Manuscript/artifacts/feature_selection/` | Frozen v4 definitions and drop evidence |
| `NATRIX_Q1_Manuscript/paper/` | Manuscript sources, bibliography, Elsevier template, build script, compiled PDFs |
| `NATRIX_Q1_Manuscript/data/` | Data provenance only; raw corpora are **not** redistributed |
| `Ai-Agent/ml_engine/` | Unmodified production modules `feature_registry.py` and `csic_evaluation.py` used by the evaluation code |

| `Ai-Agent/models/v2.0/` | Small 16-D threat-typing and anomaly models used for class labels by the serving adapter |

The authoritative file list, sizes and SHA-256 hashes are in `MANIFEST.csv` and
`SHA256SUMS.txt`, generated by `submission/make_package.py` in the source
workspace.

## What is not included

- **Raw HTTP corpora.** CSIC 2010, ECML/PKDD 2007, SR-BH 2020 and OpenAppSec WCP
  are public but are not redistributed here. `NATRIX_Q1_Manuscript/data/README.md`
  gives the source URLs, licences, retrieval dates and checksums.
- **Parquet request caches.** `experiments/results/**/*.parquet` contain request
  text and are excluded. They can be regenerated with the CRS replay scripts.
- **Third-party binaries.** Tectonic, the bundled JRE, and `tla2tools.jar` are
  not included. See `REPRODUCIBILITY.md` for installation.
- **Live or shadow-mode traffic.** All results are from offline labelled corpora
  and local replay. No production traffic, canary host, or labelled observation
  window is included.

The released `latency_inputs.json` is sanitized: credential-like URL, form and
JSON values are replaced with same-length `~` placeholders. Request count,
structure and field lengths are preserved; the reported timings were measured
on the original corpus.

## Quick start

The package mirrors the source workspace layout:

```text
NATRIX_reproducibility_v1.0.0/
  NATRIX_Q1_Manuscript/
  Ai-Agent/
  README.md
  REPRODUCIBILITY.md
  ...
```

`NATRIX_Q1_Manuscript/experiments/scripts/common.py` expects the sibling
`Ai-Agent/ml_engine/` directory, so keep the two top-level directories together.

```powershell
cd NATRIX_Q1_Manuscript

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r ..\requirements.txt

# Download the four corpora into data/raw/ as described in data/README.md.
# Then run the main queue:
.\experiments\run_all.ps1
```

The main queue needs the ONNX serving adapter on `127.0.0.1:5001` for the
latency step:

```powershell
python experiments\scripts\serve_gate.py --port 5001
```

The queue is idempotent: it overwrites files under `experiments/results/`,
`tables/` and `figures/`. The checked-in results are the measured outputs used
in the manuscript; re-running on different hardware or library versions may
produce small numerical differences.

For the additional Gate C, v3-D, P2 path-only, control/stacker, SR-BH scale and
char-CNN runs, see `REPRODUCIBILITY.md`.

## Build the manuscripts

The Elsevier source is `paper/manuscript_short.md`; the IEEE source is
`paper/manuscript_ieee.tex`.

```powershell
python paper\build_manuscript.py --source paper\manuscript_short.md `
  --stem NATRIX_manuscript_short --template paper\elsarticle_template.tex
tectonic -X compile paper\NATRIX_manuscript_short.tex
tectonic -X compile paper\manuscript_ieee.tex
```

Tectonic is not bundled. Install it from
<https://tectonic-typesetting.github.io/> or use a TeX Live installation with
the `elsarticle` class. Pandoc 3.10 is fetched by `pypandoc` on first use.
